Still Moment

Deine Meditationen, dein Raum.

Still Moment ist eine App für geführte Meditationen aus den eigenen MP3s und für stille Meditation mit einem anpassbaren Timer. Die Bibliothek — der Aufbau einer persönlichen Sammlung aus eigenen Audiodateien — ist das Kern-Feature; der Stille-Meditations-Timer ist die Ergänzung. Alles läuft lokal auf dem Gerät: kein Konto, keine Cloud, keine Ablenkung.

Der typische Ablauf: Meditation starten, Handy weglegen, der Sperrbildschirm geht an — währenddessen passiert nichts anderes. Diese Referenz fasst zusammen, woran sich jede Design-Entscheidung misst, und dokumentiert Farb-Tokens und Typografie der App.

Design-Richtlinien

ux-conventions.md · CLAUDE.md
  • Eine Fläche, eine Aufgabe. Kein Modal-im-Modal, keine überladenen Screens. Zustandsübergänge sind explizit und sichtbar.
  • Lock-Screen-First. Der Standard-Use-Case ist: starten, Handy weglegen. Features müssen mit gesperrtem Bildschirm funktionieren — Vordergrund-only reicht nicht.
  • Kein Tab-Wechsel während einer Meditation. Läuft Timer oder Wiedergabe, ist Navigation gesperrt. Immer nur eine View vorne.
  • Hierarchie via Farbe, nicht via Token. Zehn Typo-Tokens genügen. Braucht ein Screen einen elften, ist der Screen falsch entworfen.
  • Semantische Farben, nie direkte Werte. .textPrimary statt .warmBlack. Theme kommt reaktiv über das Environment.
  • Hell = Schatten, Dunkel = Rahmen. Im Dark Mode sind Schatten wirkungslos; Karten bekommen stattdessen einen feinen Border.
  • Sanfte, lineare Bewegung. Der Timer-Ring läuft ohne Easing, kein Bounce, nichts „Verspieltes". Ruhe vor Effekt.
  • Warme, nicht-technische Sprache. Die Zielgruppe ist nicht technisch. Keine Dringlichkeit — die App ist eine Pause, keine Notification.
  • Beide Plattformen verhalten sich identisch. Gleiche Features, gleiche UX, gleiche Edge-Cases (iOS SwiftUI ↔ Android Compose).
